## Ответы на вопросы защиты
1. **Почему запись удобно представить словарём:** словарь хранит данные в виде пар «ключ — значение». Обращаться к полям по понятным именам (`record["title"]`, `record["hours"]`) намного надёжнее и нагляднее, чем запоминать числовые индексы элементов в списке. Также в словарь легко добавлять новые поля.
2. **Выбор структур:** для подсчёта частот и сумм по категориям выбран `dict` (ключ — слово/категория, значение — счётчик/сумма); для поиска общих и всех уникальных тем выбран `set` (автоматически убирает дубликаты и поддерживает быстрые операции пересечения `&` и объединения `|`); для хранения готовой пары значений выбран неизменяемый кортеж `tuple`.
3. **Поведение `get()`:** метод `dict.get(key, default)` безопасно извлекает значение по ключу. Если ключа ещё нет в словаре, он не вызывает ошибку `KeyError`, а возвращает указанное значение по умолчанию (например, `0`), что делает подсчёт в одну строчку.
4. **Причина сортировки множества перед выводом:** множество (`set`) — неупорядоченная коллекция, порядок её элементов при переборе не гарантирован. Функция `sorted()` превращает множество в отсортированный список, чтобы вывод программы всегда был одинаковым и предсказуемым.
