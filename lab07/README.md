# Лабораторная работа №7

## Две команды для запуска программ

1. Запуск основной программы:
   python main.py

2. Запуск автоматических тестов:
   python test_functions.py

## Ответы на вопросы защиты:
1. Разница между возвратом (return) и выводом (print): инструкция return завершает работу функции и отдает полученный результат обратно в ту точку программы, откуда функция была вызвана, что позволяет использовать это значение в дальнейших расчетах. Функция print просто показывает текстовое представление значения на экране человеку и возвращает значение None.
2. Локальная переменная и параметр: параметр — это переменная, которая указывается в круглых скобках при объявлении функции и принимает значения аргументов в момент вызова. Локальная переменная — это любая переменная, созданная внутри тела функции. Обе они существуют и доступны только внутри данной конкретной функции и уничтожаются после её завершения.
3. Демонстрация теста, обнаруживающего неправильное решение: если в функции sum_digits намеренно заменить строку return total на return total + 1, то при запуске файла test_functions.py первая же проверка assert sum_digits(0) == 0 обнаружит ложное условие и аварийно остановит выполнение программы с ошибкой AssertionError.
