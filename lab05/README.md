# Лабораторная работа №5

## Таблица проверок

* Программа: Нормализация
  - Ввод: " один два " -> Ожидаемый: слов 2, длина результата 8 -> Фактический: слов 2, длина результата 8
  - Ввод: "" -> Ожидаемый: длина 0, слов 0 -> Фактический: длина 0, слов 0

* Программа: Палиндром
  - Ввод: "А роза упала на лапу Азора" -> Ожидаемый: Палиндром -> Фактический: Палиндром
  - Ввод: "строка из пробелов" -> Ожидаемый: Не палиндром -> Фактический: Не палиндром
  - Ввод: "Python" -> Ожидаемый: Не палиндром -> Фактический: Не палиндром

* Программа: Замена
  - Ввод: "a::b" -> Ожидаемый: a--b, замен 2 -> Фактический: a--b, замен 2
  - Ввод: "abc" -> Ожидаемый: без изменений, замен 0 -> Фактический: abc, замен 0

* Программа: Вариант 1 (Начинается на 'а')
  - Ввод: "Анна, армия! Я читаю. Книга, край, рама." -> Ожидаемый: анна, армия, количество 2 -> Фактический: анна, армия, количество 2
  - Ввод: "!!! " -> Ожидаемый: Нет совпадений, количество 0 -> Фактический: Нет совпадений, количество 0

## Ответы на вопросы защиты:
1. Строки в Python являются неизменяемым типом данных (immutable). Это значит, что любые методы строк (например, replace или lower) не меняют старую строку в памяти, а всегда создают и возвращают абсолютно новую строку.
2. Отличие слова от подстроки: подстрока — это любая непрерывная часть строки (например, "ли" в слове "малина"), а слово — это отдельная смысловая единица текста, которая в наших задачах получается после разделения строки по пробелам методом split().
3. Знаки пунктуации при обработке палиндромов нужно задавать ДО написания основной логики программы, чтобы полностью очистить от них текст и сравнивать только чистые буквы, иначе знаки препинания нарушат симметрию строки.
