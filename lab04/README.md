Таблица проверок

* Программа: Диапазон
  - Ввод: 2, 4 -> Ожидаемый: 2, 3, 4 -> Фактический: 2, 3, 4
  - Ввод: 4, 2 -> Ожидаемый: 4, 3, 2 -> Фактический: 4, 3, 2
  - Ввод: 3, 3 -> Ожидаемый: Только 3 -> Фактический: 3

* Программа: Статистика
  - Ввод: n=3, числа -5, -2, -8 -> Ожидаемый: Сумма -15, положительных 0, максимум -2 -> Фактический: Сумма -15, положительных 0, максимум -2
  - Ввод: n=1, число 0 -> Ожидаемый: Сумма 0, положительных 0, максимум 0 -> Фактический: Сумма 0, положительных 0, максимум 0

* Программа: Повторный ввод
  - Ввод: 0, -2, 3 -> Ожидаемый: Квадрат 9, отклонено 2 -> Фактический: Квадрат 9, отклонено 2

* Программа: Вариант 1
  - Ввод: n=7, числа -12, -3, 0, 2, 10, 15, 20 -> Ожидаемый: Количество 5, сумма 20 -> Фактический: Количество 5, сумма 20

 Ответы на вопросы задания
1. Таблица значений переменной до и после итерации составлена и проверена в терминале.
2. Цикл завершается, когда условие продолжения становится ложным или срабатывает инструкция break.
3. range(a, b) не всегда соответствует условию задания №1, так как range по умолчанию шагает только вверх и не включает в себя правое конечное значение (b). Для движения вниз нужен отрицательный шаг -1, а для включения границы требуется указывать b + 1 или b - 1.
