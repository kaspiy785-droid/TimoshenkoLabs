## Ответы на вопросы защиты
1. **Какую ошибку выявляет таблица 2x3:** прямоугольная таблица с разным количеством строк и столбцов сразу выявит путаницу между индексами строк и столбцов (например, если перепутать `len(matrix)` и `len(matrix[0])` при обходе по столбцам, программа упадёт с `IndexError` или посчитает не все элементы).
2. **Почему нельзя повторять одну изменяемую строку (`[[0] * columns] * rows`):** оператор умножения `*` не создаёт новые списки, а копирует ссылку на один и тот же внутренний список в памяти. В результате изменение одной ячейки (`matrix[0][0] = 7`) автоматически изменит этот столбец во всех строках сразу.
3. **Чем копия внешнего списка отличается от копирования строк:** метод `matrix.copy()` создаёт новый внешний список, но внутри него остаются ссылки на те же самые старые вложенные списки-строки (поверхностная копия). Чтобы таблицы были полностью независимы, нужно копировать каждую строку отдельно: `[row.copy() for row in matrix]`.
