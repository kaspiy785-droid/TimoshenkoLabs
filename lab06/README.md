# Лабораторная работа №6

## Таблица проверок

* Программа: Статистика
  - Ввод: -2 0 5 3 -> Ожидаемый: количество 4, сумма 6, минимум -2, максимум 5, среднее 1.50 -> Фактический: количество 4, сумма 6, минимум -2, максимум 5, среднее 1.50
  - Ввод: "" -> Ожидаемый: Нет данных -> Фактический: Нет данных

* Программа: Преобразование
  - Ввод: -2 0 5 -2 -> Ожидаемый: новый, исходный [-2, 0, 5, -2] -> Фактический: новый, исходный [-2, 0, 5, -2]

* Программа: Позиции максимума
  - Ввод: 7 7 -> Ожидаемый: [0, 1] -> Фактический: [0, 1]
  - Ввод: -1 -2 -> Ожидаемый: [0] -> Фактический: [0]

* Программа: Вариант 1 (Чётные числа)
  - Ввод: -8 -3 0 6 6 1 -> Ожидаемый: исходном [-8, -3, 0, 6, 6, 1], количество 4, сумма 4, отсортированная копия [-8, 0, 6, 6] -> Фактический: исходном [-8, -3, 0, 6, 6, 1], количество 4, сумма 4, отсортированная копия [-8, 0, 6, 6]
  - Ввод: "" -> Ожидаемый: количество 0, сумма 0, копия [] -> Фактический: количество 0, сумма 0, копия []

## Ответы на вопросы защиты:
1. Доказательство сохранности исходного списка во втором задании: создание нового пустого списка и заполнение его через метод append() гарантирует, что элементы исходного списка считывались, но сама структура исходного списка никак не изменялась.
2. Отличие append() от присваивания по индексу: метод append() динамически расширяет размер списка, добавляя новый элемент строго в самый конец структуры. Присваивание по существующему индексу (items[i] = value) не меняет длину списка, а перезаписывает старое значение, которое уже находилось в этой ячейке памяти.
3. Отличие sorted() от sort(): метод sort() производит сортировку элементов внутри исходного списка, меняя их порядок на месте и возвращая значение None. Функция sorted() принимает список, не трогает оригинал, а создает и возвращает абсолютно новую отсортированную копию структуры.
