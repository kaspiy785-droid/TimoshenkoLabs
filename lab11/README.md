## Команды запуска
* Локальный анализ JSON: python main.py
* Запрос профиля GitHub (или локальный пример): python fetch_profile.py
* Автоматические тесты: python test_analysis.py

## Пояснение к HTTP-запросу (fetch_profile.py)
* **Адрес API:** `https://github.com<login>` — официальная точка доступа GitHub REST API для получения публичной информации о пользователе в формате JSON.
* **Метод GET:** используется по умолчанию в `urllib.request` для безопасного чтения данных с сервера без их изменения.
* **Таймаут (`timeout=10`):** ограничивает время ожидания ответа от сервера 10 секундами, чтобы программа не зависла навсегда при плохом интернете.
* **Обработчики ошибок:**
  - `HTTPError` — перехватывает коды ошибок от самого сервера (например, 404 если пользователь не найден, или 403 при превышении лимита запросов).
  - `URLError`, `TimeoutError`, `socket.timeout` — срабатывают при отсутствии интернета, ошибке DNS или превышении времени ожидания.
  - `ValueError`, `UnicodeError` — защищают от битого JSON или неожиданной структуры ответа.
  - `OSError` — обрабатывает проблемы при сохранении файла `profile.json` на диск.

## Ответы на вопросы защиты
1. **Зачем использовать `type(value) is int` вместо `isinstance(value, int)`:** в Python тип `bool` является подклассом `int` (`True == 1`, `False == 0`). Поэтому `isinstance(True, int)` вернёт `True`. Строгая проверка `type(value) is int` отсекает логические значения и пропускает только настоящие целые числа.
2. **Порядок перехвата `json.JSONDecodeError` и `ValueError`:** класс `JSONDecodeError` наследуется от `ValueError`. В блоке `try...except` более конкретное исключение (`JSONDecodeError`) должно стоять раньше более общего (`ValueError`), иначе общий блок перехватит ошибку синтаксиса JSON раньше времени.
3. **Защита от перезаписи при ошибке:** файлы `leaders.json` и `selected.json` открываются на запись (`"w"`) только в ветке `else` после того, как входной файл успешно прочитан и прошёл полную проверку в `validate_todos()`. Если в `todos.json` есть ошибка, старые результаты останутся целыми.
