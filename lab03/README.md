Лабораторная работа №3


* Программа: Минимум
  - Ввод: 2, 10, 3 -> Ожидаемый: 2 -> Фактический: 2
  - Ввод: 5, 5, 5 -> Ожидаемый: 5 -> Фактический: 5
  - Ввод: -4, 0, -2 -> Ожидаемый: -4 -> Фактический: -4

* Программа: Калькулятор
  - Ввод: 7 / 2 -> Ожидаемый: 3.50 -> Фактический: 3.50
  - Ввод: 5 / 0 -> Ожидаемый: Деление на ноль запрещено -> Фактический: Деление на ноль запрещено

* Программа: Точка
  - Ввод: 2, 2 -> Ожидаемый: внутри -> Фактический: внутри
  - Ввод: 5, 3 -> Ожидаемый: на границе -> Фактический: на границе
  - Ввод: 5.1, 3 -> Ожидаемый: снаружи -> Фактический: снаружи

* Программа: Вариант
  - Ввод: -1 -> Ожидаемый: Ошибка диапазона -> Фактический: Ошибка диапазона
  - Ввод: 0 -> Ожидаемый: Низкий -> Фактический: Низкий
  - Ввод: 100 -> Ожидаемый: Высокий -> Фактический: Высокий
  - Ввод: 101 -> Ожидаемый: Ошибка диапазона -> Фактический: Ошибка диапазона
