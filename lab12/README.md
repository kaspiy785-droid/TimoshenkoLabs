# Лабораторная работа №12 — Итоговый проект

* **Вариант:** №1 (План учебных занятий)
* **Назначение:** консольное приложение для учёта запланированных учебных часов, управления статусами выполнения и подсчёта статистики с сохранением данных в JSON.
* **Версия Python:** Python 3.13+

## Команды запуска
* Запуск консольного приложения: `python main.py`
* Запуск дополнительного графического окна: `python gui.py`
* Запуск тестов логики: `python test_logic.py`
* Запуск тестов хранилища: `python test_storage.py`

## Описание формата данных (`data.json`)
Файл хранит список словарей в кодировке UTF-8. Каждая запись содержит 5 обязательных полей:
* `id` — положительное уникальное целое число (`int`)
* `title` — непустое название занятия (`str`)
* `category` — непустая категория занятия (`str`)
* `amount` — количество запланированных часов, целое число `>= 0` (`int`)
* `completed` — статус выполнения (`bool`: `true` — занятие завершено, `false` — не завершено)

## Результаты сценариев приёмки
1. **Файла нет:** приложение выводит сообщение, стартует с пустым списком `[]`, меню работает штатно.
2. **JSON содержит `[]`:** список пуст, статистика выводит нули по всем показателям.
3. **Добавлены записи с количеством 4 и 2, вторая завершена:** статистика показывает `Всего записей: 2, Завершено: 1, Не завершено: 1, Общая сумма часов: 6`.
4. **Название введено как `  Python  `:** пробелы по краям обрезаются, сохраняется как `Python`.
5. **Поиск `py` при названии `Python`:** поиск без учёта регистра успешно находит запись.
6. **Пустое название, `amount=-1`, `amount=abc`:** программа отклоняет ошибочный ввод и повторяет запрос без создания некорректной записи.
7. **Изменение статуса неизвестного ID:** выводится сообщение о том, что запись не найдена, данные не меняются.
8. **Удаление отменено:** при вводе любого ответа кроме `да` запись остаётся в списке.
9. **Удалена запись с ID 1 из списка с ID 1 и 2:** остаётся запись с ID 2; следующая добавленная запись получает ID 3 (нумерация не сбивается).
10. **Сохранение и перезапуск:** после выбора пункта 7 (или ответа `да` при выходе) все записи и их статусы полностью восстанавливаются при следующем запуске `main.py`.
11. **Повреждённый JSON или повторный ID:** запуск прерывается до открытия меню с понятным описанием ошибки, исходный файл не перезаписывается.
12. **Ошибка сохранения:** при невозможности записать файл выводится текст ошибки, программа не закрывается принудительно и позволяет продолжить работу.
