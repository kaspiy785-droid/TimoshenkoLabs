# Лабораторная работа №10

## Описание формата файлов
* **Входной файл `matrix.txt` (UTF-8):** первая строка содержит два целых положительных числа (количество строк и столбцов через пробел). Далее идут строки матрицы с целыми числами, разделёнными пробелами.
* **Выходной файл `report.txt` (UTF-8):** содержит три строки — суммы по строкам, суммы по столбцам и результат индивидуального варианта (сумма положительных элементов).

## Команды запуска
* Основная программа: python main.py
* Автоматические тесты: python test_files.py

## Проверка сохранности отчёта
При внесении ошибки в `matrix.txt` (например, буквы вместо числа или лишней строки) программа выводит сообщение об ошибке формата в консоль, а существующий файл `report.txt` остаётся нетронутым со старыми данными.

## Ответы на вопросы защиты
1. **Отличие ошибок формата от ошибок доступа:** ошибки формата (`ValueError`, `UnicodeError`) возникают, когда файл успешно прочитан с диска, но его внутреннее содержимое не соответствует нашим правилам (пустой файл, буквы вместо чисел, неверная кодировка). Ошибки доступа (`FileNotFoundError`, `OSError`) связаны с самой файловой системой: файл не существует по указанному пути, заблокирован другой программой или нет прав на чтение/запись.
2. **Почему отчёт открывается для записи после проверки входа:** режим `"w"` в функции `open()` мгновенно стирает всё старое содержимое файла в момент открытия. Если открыть `report.txt` до чтения и проверки `matrix.txt`, то при возникновении ошибки во входных данных старый рабочий отчёт будет безвозвратно уничтожен.
